# Aprendizado Diário Área Tech

## Sobre
Repositório dedicado ao meu aprendizado diário. Aqui registro exercícios
de cursos, desafios de código e a linha de raciocínio por trás de cada
solução — não só o resultado final, mas como cheguei até ele.

## Como está organizado
Cada exercício ou desafio tem sua própria pasta, numerada pelo tema
(ex.: `conceitos_js_QA`). Dentro de cada uma: o
código, um README específico explicando o raciocínio e, quando
relevante, a versão anterior antes da refatoração — para eu acompanhar
minha própria evolução.

## O que você vai encontrar aqui
- Exercícios de lógica de programação, resolvidos e documentados
- O raciocínio por trás da solução, não só o código pronto
- Transparência sobre o uso de IA como apoio: quando usei, digo onde e
  o que eu revisei e entendi por conta própria
- Evolução de código: da primeira versão funcional até a versão
  refatorada com boas práticas (clean code)

## Tecnologias
- JavaScript (ES6+), com prática de requisições assíncronas (`fetch`,
`async/await`) e consumo de dados externos (CSV).
